# 문항 단원 분류표 (OPER-139)

풀잇 문항의 `unit_code`·`concept`를 학원 포털의 검색·출제 UI에서 쓸 **대단원 → 중단원 → 소단원** 3단계 체계로 매핑한 표. 기계용 파일은 같은 폴더의 `math_taxonomy.json`, `english_taxonomy.json`.

## 3. 메타수학 검색 UI와의 대응

| 메타수학 필터 | 풀잇 매핑 |
|---|---|
| 학년·학기 | 검색 축으로 쓰지 않음. 과목 단위(수학Ⅰ·수학Ⅱ·확률과 통계 / 영어)로 대체하고, 문항 은행 전체에 "고3 · 수능형" 태그 표시 |
| 대단원 (f_lchapter) | 위 표의 대단원 / 영어 유형군 |
| 중단원 (f_mchapter) | `unit_code` |
| 소단원 (f_schapter) | 수학 `concept` / 영어 없음 |
| 난이도 (f_difficult) | 수학 `difficulty` 상·중·하 / 영어 없음 |
| 문제유형 (f_ptype) | 객관식만 (주관식·서술형 없음) |
| 교재·페이지 (f_book) | 없음 (범위 제외) |

## 4. 결정 사항

1. 수학 소단원은 별도 코드표를 만들지 않고 `concept` 문자열을 그대로 키로 사용 (중단원당 2~12개, 총 123개).
2. 영어 유형군 이름(대의 파악·주장과 글의 흐름·추론·세부 정보 파악)은 코드 순서를 존중해 임의 명명. 화면 노출 시 변경 가능.
3. 난이도는 수학만 3단계(상·중·하). 영어는 오픈 후 별도 태스크에서 부여.
4. 주관식 수학 문항은 DB에 적재하지 않음.
5. 학년은 검색 축으로 만들지 않음. 현재 문항이 전부 수능 범위라 학년 필터가 무의미하고, 수학Ⅰ·Ⅱ는 고2 학원도 사용 가능하므로 과목으로 찾게 함. 대신 "고3 · 수능형" 태그를 문제지·검색 화면에 표시. DB의 단원 테이블에는 `grade` 컬럼을 nullable 로 예비해 두어 고1·중등 문항 추가 시 필터를 켤 수 있게 함.
6. 배점(`score`)은 수학 2·3·4점, 영어 2점(도표 유형 일부 3점). 문제지 총점 계산에 사용하며, 영어는 배점이 거의 균일해 난이도 대용으로 쓰지 않음.
